## ✨ Features

- 🛍️ Interactive shopping cart with quantity and price calculations.
- 💜 Wishlist management with one-click add-to-cart functionality.
- 🔎 Live product search by name, category, and ingredients.
- 🧴 Detailed product views with ingredients, benefits, and reviews.
- 🎟️ Promotional codes: `GLOW30` and `AURORA10`.
- 🚚 Free-shipping progress indicator.
- 📱 Responsive design for mobile, tablet, and desktop.
- 💾 Local storage persistence for cart and wishlist.
- ✉️ Newsletter subscription interface with email validation.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** Motion
- **State Management:** React Context API
- **Persistence:** Browser Local Storage

## 🚀 Getting Started

**Requirements:** Node.js and npm.

```bash
git clone https://github.com/GhousDeveloper/aurora-skincare.git
cd aurora-skincare
npm install
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
npm run preview
```
